apeCsound v. 1.0.0 for macOS
by Alessandro Petrolati - apeSoft

Csound 7 inside your DAW: write or load a .csd, press Apply, and play it
as a multichannel instrument and effect with host-automatable parameters.

WHAT IS INSTALLED
- apeCsound.app        -> /Applications
- apeCsound.component  -> /Library/Audio/Plug-Ins/Components   (Audio Unit)
- apeCsound.vst3       -> /Library/Audio/Plug-Ins/VST3          (VST3)

Csound is built into apeCsound: no separate Csound installation is needed.
Your .csd files are saved by default in ~/Documents/apeCsound.

GETTING STARTED
1. Insert apeCsound on a track of your DAW (or open the standalone app;
   choose the audio device from the menu: Audio/MIDI Settings...).
2. Edit the template or load a .csd (click the file name in the toolbar).
3. Press Apply. Messages and errors appear in the console.
4. Open the main menu > apeCsound Guide for the full documentation.

NOTES
- If the plug-in does not appear in your DAW, rescan the plug-ins
  (Logic: Settings > Plug-in Manager > Reset & Rescan).
- Files made for Cabbage or CsoundQt: only the supported parameters are
  imported, and whether a file runs depends on many factors (see the Guide).
