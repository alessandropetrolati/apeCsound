APECSOUND - RELEASE NOTES
=========================

1.0.4
-----

Built on Csound 7.0.0, the official release (tag 7.0.0, 21 October 2026). The
previous builds used a develop snapshot; every platform now builds from the
same tagged sources.

ENGINE

  * Csound 7.0.0 linked statically on macOS, iOS, Windows and Linux.
  * OSC opcodes built in (oscinit, osclisten, oscsend, oscbundle, oscraw;
    the uppercase names still work as aliases): liblo and the OSC plugin
    are compiled into the binary and registered on every engine instance.
  * NSLocalNetworkUsageDescription on iOS and macOS: the local-network
    permission for OSC is requested with a proper message.
  * Pause button next to Apply: stops Csound and passes the audio through;
    Apply restarts it.
  * Audio scaling fixed: the output and input are scaled by 0dbfs; a .csd
    with 0dbfs = 32767 is no longer 32767 times too loud.
  * Two-way channels: chnset on a mapped channel moves the parameter
    (slider, host, automation) instead of being overwritten every block.
  * Parameter names and ranges are refreshed in the DAW after Load.
  * Console flood protection: identical messages repeated more than three
    times per second are summarised; the console no longer freezes the
    DAW.
  * Warning in the console when a parameter channel is also used as an
    audio channel (chnget/chnset with a variables), which Csound rejects.

PLUG-IN TYPE

  * The AU / AUv3 is now a Music Effect (aumf): an audio effect that also
    receives MIDI. VST3 stays Fx. One plug-in for every use: to play a
    .csd instrument, load apeCsound as an effect and send it MIDI (the
    Guide explains how in Logic, Ableton Live, Cubase, REAPER, Bitwig,
    Studio One and the iOS hosts). Logic also lists it in the instrument
    slot under "AU MIDI-controlled Effects".

PARAMETERS PANEL

  * Groups: a ; @group Name comment in the code puts the parameters read
    below it - sliders, toggles and menus alike - under one collapsible
    frame; the group of a channel is where its first chnget is; parameters
    without a group go to "Other". Expand All / Collapse All in the +
    menu.
  * Snapshots (camera button on the right of the title bar): named sets of
    parameter values stored in the .csd and in the DAW project. Save,
    Recall, Overwrite, Rename, Delete; saving/renaming/deleting can be
    undone.
  * Compact cards: the channel name sits in the title row (no more
    "SLIDER FLOAT" label); toggles and menus are single-line cards.
  * The copy icon of each card is now a "..." menu: Copy chnget line, Reset
    to Init Value, Randomize, Show in Code, Remove (with confirmation); the edit button
    shows a pencil, and a check mark (apply) while the card is in edit mode.
  * "Randomize All" in the "+" menu of the Parameters panel.
  * Live preview: while editing a Float/Int slider the real slider stays
    visible under the name field and follows every change of Min/Max/Init/
    Skew/Step as you type.
  * Evaluate (live coding): Shift+Return or the right-click menu sends the
    selection, the instr/opcode block around the caret or the current line
    to the running engine without a full recompile (instr redefinition,
    global code, score events); the help bar turns into an Evaluate line
    (">_" icon or Cmd+E) for one-liners, with history.
  * Code <-> Parameters link: with the caret on a chnget/chnset line, the
    card of that channel flashes briefly in the Parameters panel; "Show in Code"
    in the "..." menu of a card selects its channel name in the code.
  * One card in edit mode at a time, outlined in the colour of its type;
    inline validation of min/max/init/skew/step, options and duplicate
    channel names.
  * A dot flashes next to the name when a value is changed from outside
    (DAW automation, chnset, snapshot recall).
  * Larger sliders, with a touch-friendly thumb; on touch screens a
    horizontal drag moves the slider and a vertical one scrolls the panel.
  * Min/max labels shown as floats.

EDITOR

  * Graphs panel docked at the bottom, next to the console: function
    tables and display / dispfft signals drawn in the plug-in instead of
    ASCII graphs in the console; displays always on.
  * Find / Replace bar (magnifier button): match case, whole word, Replace
    / Replace All; Esc closes it.
  * Keyboard shortcuts, the same in the plug-in and in the standalone app:
    Cmd+Return Apply, Cmd+S / Cmd+Shift+S / Cmd+O / Cmd+N, Cmd+F,
    Cmd+1/2/3 panels, Cmd+= / Cmd+-, Cmd+Z / Cmd+Shift+Z, Cmd+/ comment,
    Ctrl+I re-indent, Cmd+[ / ].
  * Undo / Redo move the caret and the selection to the edited text and
    scroll it into view.
  * Block comments /* ... */ keep their colour after edits and scrolling.
  * apeCsound Guide rewritten: full-screen, laid out in sections with
    proper lists; scrolls with wheel, trackpad and finger.
  * The console scrolls with the finger on iOS.

FILES AND SESSIONS

  * Factory examples built into the binary and extracted to CSD/Examples
    on first launch (Cabbage and CsoundQt collections with credits and
    licences in README_Examples.md, plus ape/ and Test/). Open Example...
    and Restore Examples in the file menu.
  * Sessions live in ~/Documents/apeCsound/CSD: CSD/User is the default
    for Save as, CSD/Examples holds the examples.
  * Import Files... on every platform: the dialog shows only the supported
    types and copies each file to the right folder (.csd to CSD/User,
    audio to SSDIR, .udo/.inc/.txt to INCDIR, analysis files to SADIR).
  * Manage Files...: on desktop opens the apeCsound folder in Finder /
    Explorer; on iOS a file manager over the shared folder (import into a
    folder, export to the Files app, delete).
  * iOS file browser for Load / Open Example / Save as, presented like the
    system sheet: the shared App Group folder is not visible in the Files
    app, so apeCsound shows it itself; "Other Locations..." opens the
    system picker.
  * Config > Extra Folders (was "Csound Folders") on every platform: extra
    SSDIR / SADIR / INCDIR folders and the SFDIR output folder; on iOS
    chosen with the system picker and shared by the app and the AUv3.
  * .csd files associated with apeCsound on macOS and iOS (double click /
    Open in).
  * File menu reorganised in groups: Init, Load / Open Example, Save /
    Save as / Reveal in Finder, Import / Manage Files, Restore Examples.

MENUS AND UI

  * Touch-friendly menus on iOS and Android only; desktop keeps the
    native-style popup. Icons on every platform, keyboard shortcuts shown
    on desktop only; wider gap between icon and text.
  * Config menu: Modern Syntax in Help, Follow CSD nchnls, Light Editor,
    Extra Folders.
  * About: engine build line and credits for the examples.

BUILD AND DISTRIBUTION

  * Static Csound build scripts for macOS (universal), iOS (device +
    simulator), Linux and Windows, all pinned to the 7.0.0 tag; the OSC
    plugin is patched to build statically.
  * GitHub Actions for Windows and Linux: VST3 + Standalone, zipped.
  * README rewritten: formats per platform, download links, features,
    build steps.
